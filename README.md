# nitrogenbear.github.io

Holds `.well-known/assetlinks.json`, which lets the Stitch Jobs Android app
(`io.github.nitrogenbear.stitchjobs`) open https://nitrogenbear.github.io/Craft-Recycle-with-Stitch/
full-screen without an address bar. `.nojekyll` makes GitHub Pages publish the `.well-known` folder.
